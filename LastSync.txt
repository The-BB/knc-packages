    fwupd: update to version 2.1.8
    
    See https://github.com/fwupd/fwupd/releases/tag/2.1.8
    
    Remove backported patches which were adding support for
    the MaxLinear MxL862xx switch family to 2.1.7 downstream.
    
    Restore the glib2 host build dependency
    
    src/meson.build calls gnome.compile_resources(), which resolves
    glib_compile_resources from the staged gio-2.0.pc. glib2 rewrites that
    variable to point into staging_dir/hostpkg, as a cross-built generator
    cannot run on the build host, so fwupd has to build glib2/host. With
    the dependency gone, meson only configures when an unrelated package
    stages the host tools first, and otherwise fails with "tool variable
    'glib_compile_resources' contains erroneous value".

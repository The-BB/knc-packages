    libevdev: depend on input-support for the evdev nodes
    
    /dev/input/* is 0600 root:root unless input-support is installed to
    allocate the input group and ship the hotplug rule, so a program reading
    evdev has to run as root without it.
    
    libinput depends on libevdev and inherits this, so both sides of the
    evdev stack are covered by saying it once here.
